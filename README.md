# Flodljus Manager

Ett fotbollsmanagerspel i webbläsaren med molnsparning på egen server.

| Mapp/fil | Innehåll |
|---|---|
| `flodljus-spel/` | Själva spelet (öppna `index.html`) |
| `flodljus-api/` | Sparnings-API (Node + Postgres) |
| `nginx/`, `docker-compose.flodljus.yml` | Serverinstallation |
| `INSTALLERA.md` | Steg-för-steg-instruktion för servern |
| `UPPDATERA.md`, `uppdatera.ps1` | Hämta nya versioner till servern från GitHub |

Historiken flyttades hit från repot `Testrun` (mappen `flodljus/`).
